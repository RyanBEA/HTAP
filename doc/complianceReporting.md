# NBC 2020 Energy Compliance Form Generation

## Purpose & Scope
The compliance reporting system generates NBC 2020 Energy Compliance Forms programmatically from HOT2000 simulation data. Rather than constructing Word documents from scratch, it uses a template-and-fill approach:
1. Extract fillable template from the authoritative NBC form
2. Map data fields using a coordinate system
3. Fill templates via string substitution with simulation results

This approach ensures forms remain synchronized with official NBC requirements while enabling automated generation from HTAP runs.

## Location
- **Source documents**: `complianceReporting/`
- **Generation scripts**: `util/build_fillable_form.py`, `util/fill_form_dummy_data.py`
- **Field mapping**: `complianceReporting/form_template_fields.json`
- **Example models**: `complianceReporting/*.h2k` (reference data only)

## File Structure

### Core Documents

**form.docx** (53 KB)
- Official NBC 2020 Energy Compliance Form
- Read-only authoritative source
- 18 tables with 137 data cells (light blue fill color `#DEEAF6`)
- All table structures, borders, fonts, and styling preserved

**form_template.docx** (48 KB)
- Programmatically fillable template with placeholder tokens
- Generated by `util/build_fillable_form.py`
- Identical structure to original, but data cells contain `{{T#_R#_C#}}` placeholders
- All formatting, merged cells, and styling preserved

**form_filled_dummy.docx** (49 KB)
- Example completed form with representative test data
- Generated by `util/fill_form_dummy_data.py`
- Demonstrates the fill workflow with sample building data

**form_template_fields.json** (19 KB)
- Maps 137 placeholder IDs to their semantic meaning
- Provides row/column labels for each field
- Used to understand what data belongs in each cell

## Field Coordinate System

Each fillable field uses a coordinate-based identifier:

```
Format: T<table>_R<row>_C<column>

Examples:
  T0_R1_C1  = Table 0, Row 1, Column 1 (Project Name)
  T5_R13_C1 = Table 5, Row 13, Column 1 (Front orientation)
  T14_R27_C5 = Table 14, Row 27, Column 5 (Furnace efficiency)
```

**Indexing**: Zero-based for both rows and columns
**Labels**: Field mapping includes semantic labels extracted from:
- `row_label` - Text from first column of that row
- `column_label` - Text from header row (row 0) of that column

**Example field mapping entry**:
```json
{
  "T5_R13_C1": {
    "table": 5,
    "row": 13,
    "column": 1,
    "row_label": "Front orientation of house (N, NE, E, SE, S, SW, W, NW):",
    "column_label": "Reference Model"
  }
}
```

## Generation Workflow

### Step 1: Build Fillable Template (One-Time Setup)

**Script**: `util/build_fillable_form.py`

```bash
cd C:/HTAP
python util/build_fillable_form.py
```

**Process**:
1. Opens `form.docx` as ZIP archive
2. Extracts and parses `word/document.xml` with namespace-aware ElementTree
3. Identifies all cells with light blue fill (`w:shd w:fill="DEEAF6"`)
4. Replaces cell content with placeholder tokens `{{T#_R#_C#}}`
5. Captures row/column labels for field mapping
6. Writes `form_template.docx` and `form_template_fields.json`

**Output**:
- `complianceReporting/form_template.docx` - Template with 137 placeholders
- `complianceReporting/form_template_fields.json` - Field metadata

**When to run**: Only when `form.docx` is updated with new NBC requirements

### Step 2: Fill Template with Data

**Script**: `util/fill_form_dummy_data.py`

```bash
cd C:/HTAP
python util/fill_form_dummy_data.py
```

**Process**:
1. Loads field mapping from `form_template_fields.json`
2. Builds value dictionary mapping field IDs to data
3. Opens template, extracts `word/document.xml`
4. Performs string substitution: `{{FIELD_ID}}` → actual value
5. XML-escapes values to handle special characters
6. Writes completed form to output file

**Output**:
- `complianceReporting/form_filled_dummy.docx` - Example completed form

**Value Dictionary Structure**:
```python
values = {
    'T0_R1_C1': 'Sample Project Name',
    'T0_R2_C1': '123 Main Street, Halifax, NS',
    'T5_R13_C1': 'S',  # Orientation
    'T5_R14_C2': '1.40',  # Window U-value
    # ... 133 more fields
}
```

## Key Technical Details

### Document Format (Office Open XML)
- `.docx` files are ZIP archives containing XML files
- Primary content in `word/document.xml`
- All other files (styles, relationships, theme) copied unchanged
- Only `document.xml` is modified during fill process

### Light Blue Cell Marker
- XML attribute: `<w:shd w:fill="DEEAF6"/>`
- Color code: `#DEEAF6` (light blue)
- This marker identifies data cells vs. static form content
- Automatically detected by `build_fillable_form.py`

### Placeholder Format
- Pattern: `{{FIELD_ID}}` (double braces)
- Simple text tokens, not Word fields
- Enables straightforward string substitution
- Unlikely to collide with real building data

### XML Special Character Handling
- Values are XML-escaped using `xml.sax.saxutils.escape()`
- Handles: `<`, `>`, `&`, apostrophes, quotes
- Example: `"Owner's Name"` → `"Owner&apos;s Name"`

### Namespace Preservation
- Critical: Must register all XML namespaces before parsing
- Ensures `w:`, `wp:`, `r:` prefixes preserved in output
- Without this, ElementTree uses full namespace URIs instead
- Handled by `load_namespaces()` function

## Script Reference

### build_fillable_form.py (137 lines)

**Purpose**: One-time generation of template from official form

**Key Functions**:
- `load_namespaces(xml_bytes)` - Extracts XML namespace declarations
- `text_in_element(element, ns)` - Extracts text from Word XML cells
- `ensure_paragraph_with_placeholder(cell, placeholder, w_ns, ns)` - Replaces cell content with placeholder token
- `build_fillable_template()` - Main logic for template generation

**Dependencies**: Python 3 standard library only (zipfile, xml.etree.ElementTree, json)

### fill_form_dummy_data.py (258 lines)

**Purpose**: Fill template with test or real data

**Key Functions**:
- `load_field_map()` - Loads field mapping JSON
- `build_sample_values(field_map)` - Creates test data dictionary (60+ explicit values)
- `generate_document(template, output, values)` - Performs string substitution
- `main()` - Orchestration function

**Dependencies**: Python 3 standard library only (zipfile, json, xml.sax.saxutils)

**Value Requirements**:
- All 137 fields must have entries (empty string is acceptable)
- Missing fields will leave placeholders in output
- Values automatically XML-escaped for special characters

## Example: Complete Fill Workflow

```python
#!/usr/bin/env python3
# fill_nbc_form.py - Example integration script

import json
import sys
from pathlib import Path

# Import the fill function from util
sys.path.insert(0, str(Path(__file__).parent / "util"))
from fill_form_dummy_data import generate_document, load_field_map

def create_compliance_form(simulation_data, output_path):
    """
    Generate NBC compliance form from HTAP simulation results.

    Args:
        simulation_data: Dict with building performance metrics
        output_path: Where to write completed .docx form
    """
    # Load field mapping
    field_map = load_field_map()

    # Build value dictionary from simulation data
    values = {}

    # Project info
    values['T0_R1_C1'] = simulation_data.get('project_name', '')
    values['T0_R2_C1'] = simulation_data.get('project_address', '')
    values['T0_R3_C1'] = simulation_data.get('applicant_name', '')
    values['T0_R4_C1'] = simulation_data.get('applicant_address', '')

    # Climate zone
    values['T1_R3_C0'] = simulation_data.get('climate_zone', '')

    # Envelope performance (Reference vs. Proposed)
    ref = simulation_data.get('reference', {})
    prop = simulation_data.get('proposed', {})

    values['T5_R13_C1'] = ref.get('orientation', 'S')
    values['T5_R14_C2'] = str(prop.get('window_u_value', ''))
    values['T5_R25_C1'] = ref.get('heating_system', '')
    values['T5_R25_C2'] = prop.get('heating_system', '')
    values['T5_R37_C1'] = ref.get('dhw_system', '')
    values['T5_R37_C2'] = prop.get('dhw_system', '')

    # Energy consumption
    values['T11_R1_C0'] = str(ref.get('annual_consumption_gj', ''))
    values['T11_R1_C2'] = str(prop.get('annual_consumption_gj', ''))

    # Professional info
    values['T13_R1_C1'] = simulation_data.get('modeler_name', '')
    values['T13_R2_C1'] = simulation_data.get('modeler_phone', '')
    values['T13_R5_C1'] = simulation_data.get('date', '')

    # Fill any unmapped fields with empty string
    for field_id in field_map.keys():
        if field_id not in values:
            values[field_id] = ''

    # Generate completed form
    template_path = 'complianceReporting/form_template.docx'
    generate_document(template_path, output_path, values)
    print(f"Generated compliance form: {output_path}")

# Example usage
if __name__ == '__main__':
    # This would come from HTAP simulation JSON output
    sim_data = {
        'project_name': 'Example House',
        'project_address': '123 Main St, Halifax, NS',
        'climate_zone': 'Zone 6 (>5000 HDD)',
        'reference': {
            'orientation': 'S',
            'heating_system': 'Natural gas furnace, 90% AFUE',
            'dhw_system': 'Natural gas tank, 0.57 EF',
            'annual_consumption_gj': '78.5'
        },
        'proposed': {
            'window_u_value': '1.40',
            'heating_system': 'CCASHP, HSPF 10.5',
            'dhw_system': 'Heat pump water heater, UEF 3.5',
            'annual_consumption_gj': '45.2'
        },
        'modeler_name': 'John Smith, P.Eng.',
        'modeler_phone': '902-555-1234',
        'date': '2024-10-30'
    }

    create_compliance_form(sim_data, 'NBC_compliance_output.docx')
```

## Maintenance

### Updating the Official Form

When NBC updates the compliance form:

1. Replace `form.docx` with new official version
2. Ensure data cells are marked with light blue fill (`#DEEAF6`)
3. Regenerate template:
   ```bash
   python util/build_fillable_form.py
   ```
4. Review `form_template_fields.json` for new/changed fields
5. Update integration code to populate new fields
6. Test with dummy data:
   ```bash
   python util/fill_form_dummy_data.py
   ```

### Debugging Tips

**Problem**: Placeholders not replaced in output
- Check that field ID matches exactly (case-sensitive)
- Verify all 137 fields have entries in values dict
- Ensure no typos in field coordinates

**Problem**: XML corruption in output
- Verify values are properly XML-escaped
- Check for unescaped `<`, `>`, `&` characters
- Use `xml.sax.saxutils.escape()` on all values

**Problem**: Formatting lost in output
- Ensure only `document.xml` is modified
- Verify all other ZIP entries copied unchanged
- Check namespace preservation in XML parsing
