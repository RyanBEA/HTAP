# Python Style Guide

## Naming Conventions
- Use `snake_case` for functions, variables, and file names.
- Use `PascalCase` for classes.
- Use `SCREAMING_SNAKE_CASE` for constants.
- Use a single leading underscore for "protected" members.
- Use double leading underscores for "private" members.

## Formatting (PEP 8)
- Use 4 spaces for indentation.
- Limit lines to 79 characters (docstrings/comments 72).
- Use spaces around operators and after commas.
- Use two blank lines between top-level functions and classes.

## Best Practices
- Follow Zen of Python (`import this`).
- Use docstrings for all public modules, functions, classes, and methods.
- Use type hints where appropriate for clarity.
- Prefer list comprehensions for simple transformations.
