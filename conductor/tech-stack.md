# Tech Stack

## Scripting & Automation
- **Ruby:** Primary language for HOT2000 automation, archetype management, and simulation workflows.
- **Python:** Used for data processing, complex transformations, and the NBC compliance reporting module.

## Data & Configuration
- **XML (.h2k):** The primary data format for residential energy simulation files.
- **JSON:** Used for configuration, field mapping (H2K to NBC), and metadata.

## External Dependencies
- **HOT2000 CLI:** Required for performing energy calculations.
- **Python Libraries:** `xml.etree.ElementTree` for H2K parsing and (inferred) `python-docx` for report generation.

## Version Control
- **Git:** Used for source code management.
